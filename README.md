Lab assignment for GEIAL314‑B2a Software Technology Practical Lab, Miskolc University.

This repository implements object‑oriented backend for video streaming platform, converted from UML domain model to Python code skeleton and full functional logic.

- `streamy_core.py`: main source code, domain classes + integration test simulation
- `Report.md`: Lab 10 & Lab11 English lab report
- `Bonus.md`: bonus feature description document
